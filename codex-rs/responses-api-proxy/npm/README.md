# @ore-cli/ore-responses-api-proxy

<p align="center"><code>npm i -g @ore-cli/ore-responses-api-proxy</code> to install <code>codex-responses-api-proxy</code></p>

This package distributes the prebuilt [ore Responses API proxy binary](https://github.com/ore-cli/ore/tree/main/codex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/codex-responses-api-proxy.js --help
```

Refer to [`codex-rs/responses-api-proxy/README.md`](https://github.com/ore-cli/ore/blob/main/codex-rs/responses-api-proxy/README.md) for detailed documentation.
