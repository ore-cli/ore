Create the ore-sync GitHub App

A GitHub App cannot be created through the REST API, only through this manifest flow or the web form. The button below submits the manifest in fork/setup/ore-sync-app.json, so the permissions are exactly the ones the sync workflows need and nothing more.

After GitHub creates it:

  1. Install the App on ore-cli/ore.
  2. Copy the App ID into the repository secret ORE_SYNC_APP_ID.
  3. Generate a private key, and paste the whole .pem into ORE_SYNC_APP_PRIVATE_KEY.

Why an App and not GITHUB_TOKEN: a pull request opened by GITHUB_TOKEN does not trigger workflows, so a sync PR would arrive with no CI at all — which is the one thing that must not happen to a PR nobody wrote by hand.

Not in the ore-cli org? Change the form action to https://github.com/settings/apps/new to create it on your account instead.
